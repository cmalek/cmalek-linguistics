# Choosing an interface for an activity

Chapter 7 surveys command, graphical, mobile, speech, touch, gesture, tangible, wearable, and other interfaces. These labels do not form a single exclusive classification: some name a platform, others an input method, interaction style, or system function.

Requirements and the intended experience guide the selection. A mobile camera or scanner can support food recording; shared displays can support co-located group work. The useful question is what the people and activity require, rather than which technology is newest.

| Decision | Evidence to seek |
| --- | --- |
| Input and output | What users can perceive and do in context |
| Platform | Mobility, space, and device constraints |
| Shared use | Coordination and access by multiple people |
| Natural interaction | Which learned skills transfer, and where they fail |

A natural user interface draws on everyday skills such as speech or gesture. That description alone does not prove that an interface is easier to learn or use. ^[inferred]
