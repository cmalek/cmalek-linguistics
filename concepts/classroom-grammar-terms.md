# Classroom Grammar Terms

Terms from a translation-oriented glossary (A–I fragment) used with [[concepts/old-english-grammar]]. Phonetic process words overlap [[concepts/historical-linguistics-sound-terms]] and [[concepts/germanic-sound-change]]; this page keeps **morphosyntactic** labels.

## Key Ideas

| Term | Working sense in this vault |
|---|---|
| Agreement / concord | MnE mainly number on verbs; OE also gender and case on modifiers (*tilu giefu*, *tilre gife*) |
| Case | Form showing role: acc/objective as object; genitive/possessive; dative as IO (*Hēo geaf him wæstm*) |
| Analogy | Irregulars reshaped to a dominant pattern (*mouse/*mouses*; many OE strong verbs → MnE weak) |
| Anomalous | *be*/*go*, OE *bēon*/*gān* — pasts outside strong/weak classes |
| Assimilation | Adjacent sounds converge (*kissed* [t] after voiceless; Latin *in-* → *im-*/*il-*) |
| Breaking | See sound-change page (glossary only cross-refs) |
| Causative | *fell* “cause to fall”; *lay* “cause to lie” |
| Dental preterite | Weak-verb past with *t*/*d* (*heard*, OE *hīerde*) |
| Dual | OE *wit* “we two”, *git* “you two” |
| Gradation | Root-vowel change for grammar (*sing/sang*) = ablaut |
| Impersonal | Unspecified subject (*it’s snowing*); OE has a dedicated translation rule |
| i-mutation | See sound-change page |
| Function word | Prepositions, conjunctions, articles, auxiliaries — grammar not lexicon |
| Hypotaxis | Subordination (glossary defers to a grammar §) |

Also: ablative absolute (Latin); OE dative absolute as the analogue; articles *the* vs *a/an*; strong vs weak adjectives.
