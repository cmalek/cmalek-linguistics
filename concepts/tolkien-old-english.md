# Tolkien and Old English

Working list of legendarium names the notes derive from [[concepts/old-english]]. Rohan is the densest cluster: Tolkien used OE as the “translated” language of the Mark.

## Key Ideas

**Secure-looking Rohan matches (notes):**

| Name | OE cited |
|---|---|
| Orthanc | *orþanc* “skill” |
| Isengard | *īsen* + *geard* (Gimli’s “iron stronghold”) |
| Eorl | *eorl* |
| éored | *ēored* cavalry/troop |
| Théoden | *þēoden* prince/king |
| Thengel / Fengel | *þengel* / *fengel* prince |
| Gríma | *grīma* mask/visor |
| Gálmód | *gāl-mōd* licentious |
| Edoras | *edoras* enclosed dwellings |
| mearas | *mearh* horse |
| Hornburg | *horn* + *burg* |
| The Mark | not OE; Danish *mark* “country” as in Denmark |

**Other:** Déagol ~ *dīgol* secret; Ent = *ent* giant; *flet* floor/hall; Beorn *beorn* warrior; mathom *māþum* treasure; Galdor *galdor* incantation.

**Flagged in the notes or here:**

- *Éomer / Éowyn / Éomund* as *wesan* subjunctive *eo-* + *mǣre/wynn/mund* is a stretch; horse-compound *eoh* is the usual philological reading. ^[ambiguous]
- *Westu Théoden hál*: *westu* is not a normal attested spelling; the greeting is the familiar *wes þū hāl* type. ^[ambiguous]
- Háma as *hāma* “cricket” because he announces visitors is playful, not demonstrated. ^[inferred]
- Helm vs French diminutive *-et* on *helmet* is a modern-English aside.

Tolkien also wrote on translating [[references/beowulf]]; this page is only the name-horde.
