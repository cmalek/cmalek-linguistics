# Historical Linguistics Sound Terms

A reading glossary for labels that show up constantly in [[concepts/germanic-sound-change]] and [[concepts/old-english-pronunciation]], even when the goal is reading rather than phonetics as such.

## Core types

| Term | Plain meaning | Why it matters here |
|---|---|---|
| Vowel / consonant | Open vs obstructed airflow | Named laws often target one class |
| Stop | Full closure and release | Grimm is often stated in stops |
| Fricative | Narrow-airflow friction | Germanic `f, þ, h, s` |
| Nasal / liquid / glide | Nose; `l r`; `j w` | Assimilation; i-mutation triggers |
| Voiced / voiceless | Vocal-fold vibration | Verner; OE fricative voicing |
| Aspirated | Extra puff of breath | Older stop systems; English *pin* vs *spin* |
| Place | Labial, dental, alveolar, palatal, velar | Classifying Grimm outcomes and OE `ċ`/`ġ` |

Kurdi (2016) separates **phonetics** (physical/physiological/psychological description and transcription of speech sounds; IPA as a one-symbol-one-sound ideal) from **phonology** (how those sounds pattern in a language). That split is the NLP-facing counterpart of this glossary. ^[inferred]

## Reconstruction vocabulary

Used constantly in [[concepts/germanic-sound-change]] explanations:

| Term | Plain meaning |
|---|---|
| Reconstructed form | Unattested, inferred; written with `*` (`*fōtiz`) |
| Proto-language | Reconstructed ancestor (e.g. Proto-Germanic) |
| Reflex | Later descendant (OE *fōt* ← earlier Gmc; ModE *foot* ← OE *fōt*) |
| Cognate | Inherited match from a shared ancestor, not mere resemblance |
| Sound correspondence | Recurring match (English `f` ~ Latin `p`) |
| Comparative method | Reconstruct by regular correspondences across related languages |
| Internal reconstruction | Infer an earlier stage from irregularities *inside* one language |
| Ablaut | Inherited vowel alternation in a family/paradigm, **not** triggered by a neighboring sound now (`sing/sang/sung`; PIE `*ped-` ~ `*pod-`) |
| Ablaut grade | e-grade, o-grade, or zero-grade (vowel gone: schematic `*bher-` / `*bhor-` / `*bhr-`) |
| Umlaut / mutation | Later change: a following vowel or glide alters the preceding vowel (`fōt` ~ `fēt`) |
| Sound law | Regular change under stated conditions |
| Analogy | Reshaping by pattern pressure (`bring/brang/brung` on `sing/sang/sung`) |
| Leveling | Analogy that reduces paradigm-internal differences (`dive/dived` vs competing `dove`) |

**Assimilation (classroom example):** ME *kissed* was disyllabic with a voiced *-d*; after syncope the *d* sat next to voiceless *ss* and unvoiced to [t] (*kist*). Latin negative *in-* becomes *im-* before *m* and *il-* before *l*. Same process-family as the local changes on [[concepts/germanic-sound-change]].

**Contrast:** ablaut is an *old inherited pattern*; umlaut is a *later triggered change*. Morphosyntactic labels (*case*, *dual*, *dental preterite*) live on [[concepts/classroom-grammar-terms]].
