# Objects, coins, clothing, and transport

These images include coin faces, decorated metalwork, a helmet, a ship prow, clothing displays, and blades. Their shapes and pictured motifs can be described, but dates, findspots, makers, ownership, and museum identifications cannot normally be recovered from an uncaptioned crop. ^[inferred]

A gold-framed object appears from several angles; that visual resemblance is not a verified object identification. ^[ambiguous] Coin legends have not been fully transcribed. Keep the image available for comparison with a catalogued edition before using it as historical or linguistic evidence.
