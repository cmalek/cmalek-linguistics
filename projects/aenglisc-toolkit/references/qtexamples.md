# QtExamples (PyQt5/PySide2 ports)

QtExamples translates the official C++ Qt examples into PyQt5 and PySide2 Python, with extra examples beyond the official set. The official-examples port is marked unfinished. Clipped at 52 stars, 96.8% Python.

## Key Points

- Extra examples: GStreamer pipelines in Qt Multimedia widgets, embedding matplotlib in Qt, and adding elements over videos.
- Visitors can request an example by opening an issue with the "request for example" label.
- It targets Qt 5 bindings, so code may need changes for PySide6. ^[inferred]
- Relevance to [[projects/aenglisc-toolkit/aenglisc-toolkit|aenglisc_toolkit]]: a lookup for how a C++ Qt idiom maps to Python bindings. ^[inferred]
