# Letos (SQLite manager)

Letos is a free, open source, multi-platform SQLite database manager written in C++ with the Qt framework. It was formerly SQLiteStudio and was renamed to avoid confusion with the official SQLite project; it is not affiliated with the SQLite authors.

## Key Points

- Free to use, including in commercial environments.
- Packages come from the Releases page and OS package managers. Windows builds are code-signed through SignPath.
- Official letos.org builds bundle a proprietary Icons8 icon set; a source build does not get that set.
- The project keeps a wiki covering compilation from source and how to contribute.
- Clipped at 6.8k stars; language mix C 70.2%, C++ 28.6%, Yacc 0.8%.
- Relevance to [[projects/aenglisc-toolkit/aenglisc-toolkit|aenglisc_toolkit]]: it is a mature Qt front end over SQLite, the same pairing as the toolkit's database layer. ^[inferred]
