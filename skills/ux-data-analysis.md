# Analyzing and presenting user research

Chapter 9 separates data, analysis, and interpretation. Quantitative data are numerical or meaningfully convertible to numbers; qualitative data include descriptions, quotations, and images. One collection method can produce both.

## Analysis choices

| Approach | What it contributes |
| --- | --- |
| Mean, median, mode, percentages | Numerical description; the choice of average changes what is emphasized |
| Themes and categories | Repeated patterns and structured qualitative comparison |
| Critical incidents | Focused examination of consequential episodes |
| Analytic frameworks | A chosen level of detail, from conversation to systems of work |

Inspect anomalies before interpreting patterns. Revisit initial impressions so that early expectations do not silently determine the conclusions. A numerical encoding of qualitative material is useful only when that encoding has a meaningful interpretation.

Presentation depends on the audience and original question. Tables, diagrams, stories, and selected evidence reveal different aspects; complementary representations can help. Software supports coding and calculation but does not remove the need to justify an interpretation. ^[inferred]
