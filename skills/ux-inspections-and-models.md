# Inspections, analytics, A/B tests, and predictive models

Chapter 16 presents evaluation approaches that do not require users to be present with the evaluator. Analytics and A/B tests still depend on user behavior, unlike an inspection or a predictive calculation.

| Method | Evidence or reasoning |
| --- | --- |
| Heuristic evaluation | Inspect an interface against usability principles |
| Cognitive walk-through | Step through a task and identify likely difficulties |
| Pluralistic walk-through | Compare task paths with users, developers, and specialists |
| Analytics | Examine recorded activity |
| A/B test | Compare groups receiving different designs |
| Predictive model | Estimate performance from a formal account of actions |

Fitts' law relates target acquisition time to target size and distance. Its practical use concerns the size and placement of controls; it does not by itself evaluate a whole user experience. ^[inferred]

Recorded behavior can be unobtrusive but raises questions about participant knowledge and data collection. [[concepts/ux-data-at-scale]] covers the broader disclosure concerns. [[skills/ux-usability-and-field-studies]] provides complementary evidence from direct studies, and [[skills/ux-evaluation-planning]] explains method selection.
