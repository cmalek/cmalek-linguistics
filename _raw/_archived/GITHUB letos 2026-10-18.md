## README

A free, open source, multi-platform SQLite database manager written in C++, with use of Qt framework.

### Formerly SQLiteStudioThis project was previously known as SQLiteStudio. The name was changed to avoid confusion with the official SQLite project, as Letos is an independent application not affiliated with the SQLite authors. More details [here](https://github.com/pawelsalawa/letos/wiki/FAQ#why-did-the-project-change-name-to-letos).
