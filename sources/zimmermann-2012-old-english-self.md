# Zimmermann 2012: [[concepts/old-english|Old English]] self

Richard Zimmermann, “Self as a non-postposing element in Old English,” *Generative Grammar in Geneva* 8 (2012): 39–58. The PDF was read for the classification of *self*, not for the word-order argument that is the article’s main subject.

He distinguishes reflexive, intensifying, and pronominally reinforced *self*. Reflexive *self* stands with a pronoun that is an object coreferential with the subject. It alternates with the bare pronoun, so it is optional. The pair he prints is Ælfric: *se Hælend sealed hine sylfne* beside *se hælend nolde hine betellan*. ^[extracted]

The Wulfstan line he quotes is *he sceal losian sylf*, glossed “he shall be lost himself.” That *sylf* is not the object reflexive in his classification. ^[extracted]
