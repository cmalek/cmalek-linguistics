# Germanic Lexicon Project: Bosworth-Toller digitization lineage

## Findings

The project’s own account dates scanning and initial OCR to 2001, followed by automated and manual correction. A July 2020 notice directs readers to the Charles University continuation, begun around 2010, as a better-corrected successor. The downloadable text and search interface belong to the same correction workflow.

## Limits

This establishes dependence between digital versions, not their present error rates. The page is explicitly historical; its description of weekly updates is not proof of the current update schedule. Differences between derivatives can reflect corrections rather than independent lexical discovery. ^[inferred]
